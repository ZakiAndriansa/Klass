# docker

**Pemilik:** Zaki · **Reviewer wajib:** Zaki · **Status:** dikerjakan nanti

Tempat berkas untuk menjalankan Klass di server: `Dockerfile` aplikasi, `Dockerfile` worker, dan konfigurasi Caddy (HTTPS).

Untuk pengembangan di laptop, `compose.yaml` di akar proyek menjalankan MySQL **dan** aplikasi Next.js dalam mode pengembangan lewat `docker compose up`. `Dockerfile` produksi belum dibuat.
